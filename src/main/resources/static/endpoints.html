Maven Commands

mvn spring-boot:run Start the Spring Boot application (click to run)
mvn clean install Clean and build the project (click to run)
mvn test Run all tests (click to run)

Social App API Endpoints

WhatsApp Endpoints

GET /social-app/wa/traverse
Traverse WhatsApp contacts and groups
GET /social-app/wa/archive
Archive support groups
GET /social-app/wa/unarchive
Unarchive support groups
GET /social-app/wa/broadcast
Broadcast message to all groups
GET /social-app/wa/broadcast/known-clients
Broadcast to known consultant clients
GET /social-app/wa/broadcast/unknown-clients
Broadcast to unknown consultant clients
GET /social-app/wa/test
Test endpoint

Telegram Endpoints

GET /social-app/tg/traverse
Traverse WhatsApp and join new Telegram groups
GET /social-app/tg/broadcast
Broadcast self skills to Telegram groups
GET /social-app/tg/test
Test endpoint

Facebook Endpoints

GET /social-app/fb/broadcast/skillset
Broadcast self skills to Facebook groups
GET /social-app/fb/broadcast/sensitive/skillset
Broadcast to sensitive Facebook groups
GET /social-app/fb/broadcast/greet-off-freelancer
Greet off freelancers in Facebook groups
GET /social-app/fb/test
Test endpoint
